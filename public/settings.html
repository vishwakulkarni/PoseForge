A

Codex CLI

Best zero-workflow local option if your Codex plan includes image generation.

  1. Install: npm install -g @openai/codex
  2. Authenticate: codex login
  3. Verify: codex --version
  4. Return here and refresh engine status.
No API key is saved in PoseForge.
B

ComfyUI

Best advanced local option for explicit pose nodes, checkpoints, LoRAs, and reproducible workflows.

  1. Install the official desktop app, or run pip install comfy-cli then comfy install.
  2. Launch locally: comfy launch -- --listen 127.0.0.1 --port 8188.
  3. Install the checkpoint, pose preprocessors, and custom nodes required by your workflow.
  4. In ComfyUI, enable developer options and export with Save (API Format).
  5. Replace the appropriate widget values with the placeholders below, then paste the JSON above.
Keep ComfyUI bound to 127.0.0.1; do not expose port 8188 to the internet.
C

Google Antigravity CLI

Agent-driven Gemini generation using the locally installed agy binary and your Google Antigravity plan.

  1. macOS/Linux: curl -fsSL https://antigravity.google/cli/install.sh | bash
  2. Windows PowerShell: irm https://antigravity.google/cli/install.ps1 | iex
  3. Open a fresh terminal and run agy once to complete setup, trust the workspace, and sign in.
  4. Verify cached authentication with agy models.
  5. Return here and refresh status. PoseForge uses documented headless JSON mode with sandboxed auto-approval because headless sessions cannot display file-tool permission prompts.
Official CLI version checked August 4, 2026: v1.1.10. Headless runs use cached credentials and never store your Google login in PoseForge.
