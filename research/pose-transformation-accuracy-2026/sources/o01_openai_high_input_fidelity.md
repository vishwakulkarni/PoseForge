## Verbatim quotes

> “When using high input fidelity, faces are preserved far more accurately than in standard mode. Use this when you need people to remain recognizable across edits.”

> “Currently, while all input images are preserved with high fidelity, only the first one you provide is preserved with extra richness in texture.”

> “When working with multiple faces from different photos, try combining all needed faces into a single composite image before sending the request.”

## Notes

Directly supports high-fidelity inputs and careful first-image/composite ordering for legacy GPT Image models. It is not an independent comparative benchmark and does not establish pose accuracy.
